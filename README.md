# Javones y mazmorras
Proyecto en Java sobre javones y mazmorras

-Funciones de cada clase

-Clase Personaje (clase base)
Clase base de todos los personajes. Representa a cualquier personaje del juego, mantiene su información básica (nombre, nivel, puntos de vida) y controla la protección, la vida y el inventario.

-Clase Mago (hereda de Personaje)
Personaje especializado en lanzar hechizos. Gestiona el maná para poder usar habilidades mágicas y puede recargarlo.

-Clase Guerrero (hereda de Personaje)
Personaje de combate que puede proteger a otros y controla qué personaje está protegiendo y permite empezar o dejar de protegerlo.

-Clase Ladron (hereda de Personaje)
Personaje ágil capaz de volverse invisible y realizar acciones especiales relacionadas con el sigilo. Gestiona su estado de invisibilidad.

-Clase Inventario
Gestiona los objetos que tiene un personaje y permite añadir objetos y consultar los que contiene.

-Clase Equipamiento
Representa los objetos que los personajes pueden usar. Mantiene información sobre el nombre y el tipo de cada objeto.
